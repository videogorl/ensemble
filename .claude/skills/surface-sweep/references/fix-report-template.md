# Surface Sweep Fix Report Template

Write `fix-report.json` for agents first. Optionally also write `surface-sweep-fix-report.md` for human scanning. The intended reader is a future fixing agent, so every issue should be actionable without replaying the whole sweep.

## Quality Bar

Each promoted finding must have:
- exact route and interaction steps,
- at least one visual or accessibility artifact,
- log excerpt when the symptom is timing, state, playback, sync, download, or crash related,
- likely owner files or search terms,
- fix strategy and post-fix verification.
- matching entry in `fix-report.json`.

Do not overfit. If the best explanation is uncertain, mark confidence Medium or Low and name the missing evidence.
